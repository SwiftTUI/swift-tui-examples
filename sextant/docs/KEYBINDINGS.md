# Sextant key bindings

`CommandCatalog` generates this file.

## Navigation

| Key | Command |
| --- | --- |
| `↑ / k` | Move selection up |
| `↓ / j` | Move selection down |
| `← / h` | Move to parent directory |
| `→ / l` | Enter the selected directory |
| `Return` | Preview the file or enter the directory |
| `Home / g` | Select first item |
| `End / G` | Select last item |
| `Page Up` | Move one page up |
| `Page Down` | Move one page down |

## Preview

| Key | Command |
| --- | --- |
| `Tab` | Switch browser and preview |
| `Escape` | Return focus to browser |

## View

| Key | Command |
| --- | --- |
| `/` | Filter the active directory |
| `.` | Toggle hidden files |
| `r` | Refresh the active directory |
| `?` | Show help |
| `s` | Search filenames or jump to a path |
| `:` | Open command palette |

## Workflow

| Key | Command |
| --- | --- |
| `b` | Toggle bookmark |
| `o` | Open with the system default |
| `e` | Edit with VISUAL or EDITOR |
| `R` | Reveal in Finder |
| `y` | Copy absolute path |
| `Y` | Copy root-relative path |

## Application

| Key | Command |
| --- | --- |
| `Ctrl-D / q` | Quit |
