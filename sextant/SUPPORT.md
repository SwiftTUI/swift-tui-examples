# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
bugs. Include the Sextant version, macOS version, Swift version, terminal, and
the smallest safe reproduction.

Sextant 0.1 supports macOS 15 and newer. Linux may build in CI but is not a
packaged or supported 0.1 distribution target. Optional preview tools are
enhancements; ordinary files must remain inspectable without them.
