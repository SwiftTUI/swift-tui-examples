# Support

Use GitHub Discussions for usage questions. Use GitHub Issues for reproducible
bugs. Include the Sextant, macOS, and Swift versions. Also include the terminal
and the smallest safe reproduction.

Sextant 0.1 supports macOS 15 and newer. Linux can build in CI, but it is not a
supported 0.1 distribution target. Optional preview tools add features.
Ordinary files must remain inspectable without them.
